# Week 20 — Feedback and course reflection

**100 minutes; no additional graded worksheet or runnable lab.**

| Minutes | Activity |
|---|---|
| 0–15 | Return examination results and explain the marking scheme |
| 15–45 | Revisit practical evidence, controls and common misconceptions |
| 45–75 | Remaining CryptoVault clarification and individual contribution discussion |
| 75–95 | Reflect on protocol assumptions, safe implementation and learning progress |
| 95–100 | Record questions and close the course |

Project videos/reports are submitted before W19. This session provides clarification and feedback;
it does not add a second project assessment or alter the course's 100-point weight allocation.
The number of teams is set from actual enrolment, not assumed by this guide.
